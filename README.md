## 2. 포트폴리오 전략

- 패션·뷰티 두 작품을 **같은 4탭 구조**로 → "카테고리가 바뀌어도 같은 틀로 일하는 MD"
- 뷰티에 퍼스널컬러를 쓰는 이유: 뷰티 상품은 실제로 "쿨톤 립, 웜톤 섀도"처럼 톤으로 팔림
- 진단 결과 → 톤별 셰이드 수요 → MD 액션까지 연결 (상품 추천에서 끝나지 않게)
- **범위:** 뷰티 중 셰이드(호수)로 팔리는 색조(립·섀도·블러셔·베이스)에 집중. W컨셉 메인 기획전 23개 중 메이크업은 5개(22%)뿐이라는 걸 알고, 퍼컬 데이터가 실제로 쓰일 곳으로 일부러 좁혔다고 설명

## 4. 핵심 결론

**실제 공개 정보 (W컨셉 뷰티 메인 기획전 23개, 2026-11-12)**
- 23개 중 **13개(57%)가 할인에 쿠폰·적립·사은품·체험딜을 겹쳐 줌** → 할인율만으로는 마진을 볼 수 없음
- 문구 키워드는 **‘론칭’ 8개**로 가장 많고, ‘단독’ 3개 → 할인보다 신상·단독 소식이 메인 구좌를 차지
- 추가 혜택은 추가 할인·쿠폰 7개, 사은품 5개, 적립 2개 순
- 최대 할인율 중앙값 40% (범위 10~83%, 배너의 “~” 표기 기준)
- 메이크업 기획전은 5개(22%), 나머지는 스킨케어·헤어·센트·디바이스 등

**가정 데이터 기준**
- 가을웜 수요 31% vs 셰이드 20% → **−11%p, 소싱 1순위**. 립은 가을웜 셰이드가 1개뿐(갭 −23%p)
- 7일 안에 품절될 셰이드 **7개 전부 가을웜·겨울쿨** → 리오더 우선
- 겨울쿨 홀리데이 기획전: 할인 25% + 쿠폰 7% + 사은품 4% → 판촉비 포함 마진 **14%** (사은품 빼면 18%). 기본 할인 15%로 조정 시 **24%**
- ‘베스트 아이템’ 구좌의 노출 1천 회당 매출이 메인 배너의 2배. 퍼컬 진단 추천은 노출은 작지만 클릭률 45%
- 진단 고객 100명 중 5명 구매, 클릭 → 장바구니 구간 이탈이 가장 큼

### 5-2. 가상(가정) 데이터

| 항목 | 내용 |
|---|---|
| 브랜드 (가상) | 코랄하우스, 브리즈랩, 서리상점, 듀이폼, 가을서랍, 누아베이스 (6곳) |
| 셰이드 | 35개 = 립 13 · 섀도 8 · 블러셔 7 · 베이스 7 |
| 단독·선론칭 (`BRAND_META`) | 코랄하우스 2개/18%, 서리상점 1개/22%, 가을서랍 1개/12%, 나머지 0 |
| 진단 수요 | 봄웜 2,140 · 여름쿨 2,610 · 가을웜 3,050 · 겨울쿨 2,000 (4주, 총 9,800명) |
| 기간 | 10월 3주 ~ 11월 2주 (4주) |
| 퍼널 | 진단 9,800 → 추천 노출 9,310 → 클릭 4,190 → 장바구니 1,380 → 구매 520 |
| 기획전 (`PROMO`) | 봄웜 브랜드위크 18%+0 · 여름쿨 단독 기획 15%+5%, 적립 5% · 가을웜 단독 선론칭 12%+3%, 사은품 3% · 겨울쿨 홀리데이 25%+7%, 사은품 4% |
| 노출 구좌 (`SLOTS`) | 메인 배너, MD가 추천하는 아이템, 브랜드 하이라이트, 지금 주목할 이슈, 놓치기 아쉬운 기회, 베스트 아이템 (구좌명만 실제) |

**계산식**
- 실효 할인율 = 1 − (1 − 기본할인)(1 − 쿠폰)
- 판촉비 포함 마진율 = (실효 판매가 − 원가 − 사은품·적립 비용) ÷ 실효 판매가
- 원가율 정가의 57%, 실효 할인 1%p당 판매량 +2.5%
- 사은품·적립은 판매량에 영향 없이 비용만 발생, 적립금은 전액 사용 (보수적 가정)
- 소진 예상일 = 재고 ÷ (4주 판매량 ÷ 28)
- 노출 1천 회당 매출 = 매출 ÷ 노출 × 1,000

**톤 태깅:** 베이스는 호수(밝기) + 언더톤(C/N/W) → 밝은 웜=봄, 밝은 쿨=여름, 깊은 웜=가을, 깊은 쿨=겨울

## 6. 규칙 로직

**브랜드 운영 제안 (②)**
1. 브랜드와 같은 온도(웜/쿨)의 톤 중, 카테고리 수요 대비 −8%p 이상 부족한데 그 브랜드에 없는 셰이드 → 신규 셰이드 입고 협의
2. 발색 스와치 누락 → 상세컷 스와치 추가 요청
3. 품절 셰이드 15% 이상 → 리오더 일정 확인
4. 단독 셰이드가 없고 평점 4.55 이상 → 단독 셰이드 선론칭 협의 (실제 기획전에서 ‘론칭’·‘단독’ 문구가 많은 점 반영)

**등록 검수 (③)**: 톤 태그 · 발색 스와치 · 전성분 · 사용기한 · 상품명 컬러 수 표기(예: "(4colors)")

## 7. 기술 메모

- 진단: MediaPipe Tasks Vision `@mediapipe/tasks-vision@1.2.2` (jsdelivr, dynamic import), Face Landmarker `float16/1`, `runningMode:'IMAGE'`, `delegate:'CPU'`
